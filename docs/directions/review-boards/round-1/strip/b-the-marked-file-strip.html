Review · the strip beneath the board

B · The marked file — the whole file, drawn

The price file is drawn once, each list as big as its rows, and every fault is a mark where it sits: the dealer sees in one look that 8,679 pairings are clean and that the money is wrong in three trailer lists and a block of Parts, and presses a mark to fix that row.

The five questions, on this board

Acted on
A mark is a place, not a sentence in a wall: GFAB’s four dots sit in GFAB. Pressing one opens a callout with the rows, the money and the act (Re-band the 4, one by one).
Grouped
By place: the file’s own kinds (boats, motors, packages, trailers, parts, fees, pairings), sized by rows. The rail groups the marks’ meaning by what they cost: money, a wrong pick, tidy.
Applied
From the callout, through the same command batch as A: one row, one step, one Undo. The dot leaves the field as the row is fixed.
Dismissed
Left as meant turns a dot into a hollow grey ring for the session, then it is gone; it returns as a dot only if its row changes. An eye hides a kind; that is a view, never a dismissal.
Clean day
The same field with no marks, which is itself the picture of a clean file; the rail says what was checked.

Its silhouette against the built screens

  • Data lists the same 53 lists as rows of names and counts; B draws them as areas with no row of text, so the two never read alike.
  • Fitment A (this round) draws 434 trailers as a waffle of equal squares for one boat; B’s tiles are unequal and the unit is a list, not a trailer.
  • Home and Quotes lead with a photograph; B has none: its picture is the file.
  • The sheet is the rows themselves; B is the map that opens them.
