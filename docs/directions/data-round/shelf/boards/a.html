Direction A · the shelf, round 2

One working table

The screen’s one job (docs/SCREENS.md row 146): see every change a new Master Price File would make before anything is written, and write the ones Northside keeps as one step with one way back.

What this screen does that no other does. It is the only place a figure on the price list moves by the thousand. Any of the 3,899 changes in a 39.8 MB workbook is found in two keystrokes (/, a name or a code) and left out with one Space, and the dock counts what Apply will write before it writes it.

The order and grouping. Census → filter → lines → act. Nothing is grouped until the person groups it: the five tiles are the first filters, the toolbar narrows, and the one table’s columns are the columns that moved in whatever is showing. B settles before it shows; C reads columns before lines. A is the register an admin already knows from Excel, with the arithmetic done.

The honest constraints

  • Cost shows here because the shelf is never a customer surface; a cost column carries “Northside’s own”, by the app’s own rule. Measured: that rule does not catch Dealer Fit’s GP, Tot Parts CTD, Act CTD and Labour CTD, so the board marks them too and the build must widen the rule.
  • MU is printed as the register prints it, a ratio, because the file carries no unit.
  • The workbook is not dated inside. “Saved on this computer 12 Sep 2026” is the file’s own modified date, never its edition.
  • No quote is on this computer, so the drafts line is drawn empty. No copy has been saved, so the copy line is empty.
  • The ledger needs a record of its own; today the applied step lives in memory and catalogue events are not kept.

The mark, and what a dealer replaces

  • The change sheet carries no mark: it is a working table, and the mark would take a line from the lines. The rest page keeps Northside’s mark, small, in the bar’s disc and nowhere larger, because its first line is now the edition.
  • Northside’s accent sets the chosen filter, the chosen row and the master tick; the act stays amber. The tiles’ inks (blue change, green new, ochre can’t place, carmine swing) are tokens a dealer’s appearance can re-ink. No photograph is assumed anywhere, so nothing breaks without one.
