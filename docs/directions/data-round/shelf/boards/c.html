Columns before lines

The screen’s one job (docs/SCREENS.md row 146): see every change a new Master Price File would make before anything is written, and write the ones Northside keeps as one step with one way back.

What this screen does that no other does. It reads a re-issue the way the person who wrote it thinks of it: 1,625 Dealer Fit changes are first 20 columns with a count each, and 2,250 Parts lines are first 70 suppliers. No other screen summarises a change before showing it.

The order and grouping. Risk → structure → lines → act. Grouped by exception (the 25 and the 61), then by column per list, then by supplier; a line appears only when a column or a supplier is opened. A is one flat register; B is grouped by what a person must decide.
